# PRTS Story Terminal (PRTS 스토리 아카이브)

> **명일방주(Arknights) 비공식 · 비영리 팬 스토리 아카이브 및 3D 테라 전술 터미널**  
> **Unofficial & Non-Profit Fan Story Archive & 3D Terra Tactical Terminal for Arknights**

---

## 1. 프로젝트 소개 (Project Overview)

### 🇰🇷 한국어
**PRTS Story Terminal**은 모바일 전략 디펜스 게임 **《명일방주(Arknights)》**의 방대한 메인 테마, 인터메디, 사이드 스토리, 옴니버스 단편집을 로도스 아일랜드의 **PRTS(Primitive Rhodes Island Terminal System) 전술 콘솔 인터페이스**로 재구성하여 열람할 수 있도록 제작된 **비공식·비영리 팬 아카이브 웹 애플리케이션**입니다.

* **작전 보고서 뷰어 (Story Archive Viewer):** 국면별/스테이지별 서사 요약, 핵심 대사 인용, 인게임 공식 컷신 CG, 사후 전술 평가 및 등장인물·용어 도감 연동.
* **테라 연대기 로드맵 (Chronicle Roadmap):** 서사 계보(메인 테마·세력 연작·단독 외전), 테라력 시간순(1089년~1102년), 서비스 출시 연차순 3종 뷰 모드 지원.
* **3D 테라 전술 지도 (Terra Tactical Map):** WebGL(Three.js) 기반 3D 헥사곤 지형 고저차 렌더링, 22개 국가/지역 정보, 27개 주요 이동도시·거점 비콘, 18대 핵심 작전 기동 경로 시뮬레이션.

### 🌐 English
**PRTS Story Terminal** is an **unofficial, non-profit fan-made web archive** designed to catalog and visualize the main theme chapters, intermezzi, side stories, and vignette anthologies of ***Arknights*** through an interactive **PRTS (Primitive Rhodes Island Terminal System) tactical terminal interface**.

* **Operation Report Viewer:** Stage-by-stage narrative summaries, key dialogue quotes, official in-game cutscene CGs, post-operation evaluations, and interactive character/glossary dossiers.
* **Chronicle Roadmap:** Interactive flowchart supporting Faction Storylines, Terra Chronological Order, and Service Release Order.
* **3D Terra Tactical Map:** WebGL (Three.js) 3D hexagonal topographic map featuring 22 nations/territories, 27 major mobile cities & outposts, and 18 core operational routes.

## 4. 기술 스택 및 실행 방법 (Tech Stack & Local Setup)

* **Frontend:** React 19, TypeScript, Tailwind CSS v4, Three.js (WebGL), Lucide Icons
* **Build Tool:** Vite 8

```bash
# 의존성 설치 (Install dependencies)
npm install

# 로컬 개발 서버 실행 (Start local dev server)
npm run dev

# 프로덕션 정적 빌드 (Production build)
npm run build
```
